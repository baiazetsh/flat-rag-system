💡 About Vector Collections

  • Collections are isolated vector databases for organizing documents by topic or project
  • Vector Dimension must match your embedding model (mxbai-embed-large = 1024)
  • Distance Metric determines how similarity is calculated (cosine is most common)
  • Recreate will delete all vectors and create a fresh empty collection
  • Delete permanently removes the collection and all its vectors

⚙️ Common Use Cases

  • Separate by Topic: Create different collections for documentation, support tickets, research papers
  • Multi-tenant: One collection per customer or organization
  • Versioning: Keep different versions of documents in separate collections
  • Testing: Use a test collection before adding to production
